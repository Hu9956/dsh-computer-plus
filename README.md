# @kewen/dsh-computer-plus · 电脑操控 Plus

让 DeepSeek Harness（DSH）在后台直接操控你的 macOS 桌面应用——日常点击、输入与滚动均在后台完成，不抢鼠标、不打断你手头正在处理的工作（仅支持 macOS）。

- **后台静默操控 + 前台胶囊提醒**：底层基于 [cua-driver](https://cua.ai/docs/cua-driver)，日常操作直接向目标窗口后台投递，不移动真实鼠标、不切换当前窗口；遇到少数不支持后台点击的窗口需要借用前台时，屏幕顶部会提前 `0.8 秒` 亮起不抢焦点的状态胶囊（「即将借用前台」→「正在使用中」），结束后自动切回你原本的窗口并绿灯提示「使用完毕」。
- **逐应用安全授权与随时撤销**：首次打开或操控某个应用前，会在对话输入框上方弹出授权卡片（「仅本次会话允许 / 始终允许 / 拒绝」）；可在插件详情页随时查看、撤销或重新允许询问，撤销会立即中止正在进行的操控。
- **全模式可用 & 节省上下文**：普通对话模式与代码执行模式均可直接调用；精简为 7 个核心动作并默认折叠冗长的系统菜单栏结构，大幅减少多步操作时的 Token 消耗。
- **一键引导配置，开箱即用**：同时支持 Apple Silicon 与 Intel Mac，无需安装 Xcode 编译环境；在插件详情页即可一键安装驱动并引导开启系统权限。

## 安装与准备

### 1. 安装插件

在 DSH 侧栏打开「插件」→「添加插件」，输入仓库地址即可安装并启用：

```text
https://github.com/Hu9956/dsh-computer-plus
```

也可以从 [Releases](https://github.com/Hu9956/dsh-computer-plus/releases/latest) 下载最新的 `.tgz` 安装包，在「添加插件」时填入本地文件路径。

> **使用建议**：请与 DSH 官方实验性插件 **「Computer Use」** 二选一开启，避免同时注入两套电脑操控指令造成双倍 Token 消耗，或因模型误走官方通道而缺少逐应用授权管理与顶部状态胶囊提醒。

### 2. 环境与权限（插件详情页一键引导）

安装启用后，点进「插件」→「电脑操控 Plus」详情页即可按引导完成准备：

| 项目 | 作用 | 准备方式 |
| --- | --- | --- |
| **底层驱动 `cua-driver`** | 在后台读取应用界面控件、截取目标窗口并投递点击输入 | 详情页点击 **「一键安装」**（或复制命令在终端执行） |
| **辅助功能 + 屏幕录制（`CuaDriver`）** | 允许驱动在后台操作控件及观察目标应用窗口画面 | 详情页点击 **「申请权限」** 并在系统设置中开启开关 |
| **可选：屏幕录制（`DeepSeek Harness`）** | 配合 `Harness Plus` 对话信息面板时实时预览 10fps 操控画面；单独使用本插件可跳过，不影响电脑操控 | 需要时在详情页点击 **「申请权限」** 开启 |

## 内置工具

| 工具 | 作用 |
| --- | --- |
| `computer_launch_app` | 在后台打开（或定位已运行的）应用，返回 `pid` 与就绪窗口的 `window_id` |
| `computer_list_windows` | 列出当前运行窗口的 `pid`、`window_id` 与位置尺寸 |
| `computer_get_window_state` | 读取目标窗口界面控件编号与截图，默认折叠顶层系统菜单栏 |
| `computer_click` | 按控件编号或窗口内坐标单击 / 双击，必要时自动借用前台兜底 |
| `computer_type_text` | 向目标窗口输入文字（支持先点击指定坐标聚焦再输入） |
| `computer_press_key` | 发送按键或组合快捷键（如 `cmd+a`、`return`） |
| `computer_scroll` | 滚动窗口或窗口内指定区域 |

> **隐私与安全**：应用授权记录以 `0600` 权限原子保存在本机 `~/.dsh/computer-plus/permissions.json`；插件全部服务端接口复用宿主鉴权且仅允许本机 `owner` 访问；启用面板预览时仅在内存中保留单帧画面，不落盘、不写入会话日志。
